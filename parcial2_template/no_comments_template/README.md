# No Comments Template

Esta carpeta contiene versiones sin comentarios ni docstrings de los archivos de las unidades 4, 5 y 6.

## Archivos

- **unidad4.py** - Códigos y Codificación (sin comentarios)
- **unidad5.py** - Teoría de Canales (sin comentarios)
- **unidad6.py** - Propiedades y Capacidad de Canales (sin comentarios)

## Características

- ✅ Sin docstrings de módulo, clase o función
- ✅ Sin comentarios inline (#)
- ✅ Código funcional preservado al 100%
- ✅ Misma funcionalidad que versiones con comentarios
- ✅ Reducción de ~60-67% en líneas de código

## Estadísticas

| Archivo | Original | Sin Comentarios | Reducción |
|---------|----------|-----------------|-----------|
| unidad4.py | 1,147 líneas | 380 líneas | 66.9% |
| unidad5.py | 893 líneas | 313 líneas | 64.9% |
| unidad6.py | 1,019 líneas | 397 líneas | 61.0% |

## Uso

Los archivos se ejecutan de la misma forma que las versiones con comentarios:

```bash
python unidad4.py
python unidad5.py
python unidad6.py
```

## Nota

Estos archivos están destinados para evaluaciones o situaciones donde se requiere código limpio sin documentación. Para aprendizaje y comprensión, se recomienda usar las versiones con comentarios en el directorio padre.
